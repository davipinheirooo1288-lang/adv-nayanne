# Nayanne Lis Advocacia e Consultoria

Landing page estatica criada a partir dos templates fornecidos na pasta do projeto, preservando a identidade visual original.

## Estrutura

- `public/index.html`: pagina publicada.
- `public/styles.css`: responsividade, hotspots e animacoes.
- `public/script.js`: links contextuais de WhatsApp, animacoes e FAQ.
- `public/assets/`: imagens finais em WebP usadas no site.
- `docs/template-original/`: templates originais e prompt do projeto.
- `scripts/validate-site.mjs`: validacao local.
- `scripts/serve-site.mjs`: servidor local sem dependencias.
- `scripts/convert-assets-webp.mjs`: conversao dos assets PNG para WebP usando Chrome local.

## Publicacao

Publicado em:

- https://adv-nayanne.vercel.app/

## Comandos

```bash
npm run validate
npm run serve -- --port 4173
```
